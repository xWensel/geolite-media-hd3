# geolite-media-hd3

Fotos de la Enciclopedia de **Geolite**: fotos HD (hasta 1920 px), archivos de la o a la z, servidas con GitHub Pages en https://xwensel.github.io/geolite-media-hd3/.

No se edita a mano: lo publica `tools/publish-media.mjs` desde el repositorio del juego.
Autoria y licencia de cada foto (casi todas de Wikimedia Commons): `data/wiki/img.json` del juego, que tambien las muestra en la Enciclopedia.
